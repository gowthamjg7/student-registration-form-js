# 🎓 Student Registration Form

✨ A modern, responsive Student Registration Form built using **HTML, CSS, and JavaScript**.

Register students, validate their details, and dynamically display submitted records in a table — all without refreshing the page!

---

## 🌟 Features

- 📝 Student registration with 8 input fields
- 👤 Gender selection using radio buttons
- 📧 Email input with built-in validation
- 📍 Address, Pincode, State and Country fields
- ✅ Required-field validation
- ⚡ Dynamic table row creation using JavaScript DOM manipulation
- 🔄 Automatic form reset after successful submission
- 📱 Responsive design for desktop, tablet and mobile
- 🎨 Modern purple and lavender UI
- 🖼️ Decorative vector illustrations and gradient circles
- ✨ Smooth hover and input focus effects

---

## 🛠️ Tech Stack

- 💻 Desktop — Two-column form layout
- 📱 Mobile — Single-column form layout
- 📊 Student table — Horizontal scrolling on smaller screens
